## Why this exists

Symmetric boundaries cancel. A residual surface force, *if* it existed, would need a reason cancellation fails — e.g. traction concentrated on one face of an asymmetric fractal hull.

**Topological pinch** is that localization **hypothesis**. It is not a certified mesh result and not a thrust measurement.

## Link to momentum closure

Any force must still appear as

$$
\mathbf{F} = \oint T_{\rm eff}\cdot n\, dA
$$

([momentum-closure](https://github.com/beyond-repair/momentum-closure)).  
Pinch only partitions that integral (aft vs fore). High localization with net \(|\mathbf{F}|\) at the noise floor is **not** thrust.
